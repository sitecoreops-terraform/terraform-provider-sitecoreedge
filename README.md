# Terraform provider for SitecoreAI

This is terraform provider to enable usage and configuration of Sitecore Experience Edge resources in Terraform or OpenTofu.

See the provider in [Terraform registry](https://registry.terraform.io/providers/sitecoreops-terraform/sitecore-edge/latest/docs)

The main focus is on establishing projects and environments by using the SitecoreAI Deploy API:
* [SitecoreAI Experience Edge Admin API](https://doc.sitecore.com/sai/en/developers/sitecoreai/admin-api.html)

To use the api you will need credentials, you can use the Sitecore CLI with [Edge extension](https://doc.sitecore.com/sai/en/developers/sitecoreai/experience-edge-plugin.html) or an edge client. See [how to create Edge administration client in SitecoreAI](hhttps://doc.sitecore.com/sai/en/developers/sitecoreai/manage-client-credentials-for-a-sitecoreai-organization-or-environment.html#create-an-automation-client-for-an-environment)
